The challenge

A drone survey isn't a dataset

  • !Rows get clipped. A plot grid rarely sits exactly on the planted rows.
  • !Frames don't cover a plot. A 6 m plot is longer than one camera footprint.
  • !Visible seams. Stitching two frames leaves a brightness / contrast step.
  • !Field-edge plots fail. No near-nadir frame → smeared, black crops.

The job

Turn 3,400 overlapping oblique photos into 392 tidy, comparable, correctly-located plot images — every planted row inside, no seams, no manual cleanup.

Plot Extractor03
Key feature

Auto-fit to the rows

The grid clips rows. So the app renders each crop wider than the boundary, detects the crop rows from the tillage-ridge pattern — working even before emergence — then snaps to exactly your row count.

  • ✓Recovers clipped rows by rendering past the boundary.
  • ✓Recentres on the rows — width_shift mode.
  • ✓Reports exact area covering the rows, in m².

Set two things

rows/plot = 7  ·  mode = width_shift

7 rows, every plot

Per-trial — change the count for a different layout, or set 0 to auto-detect.

Plot Extractor06
Under the hood

Built to be hands-off

Near-nadir scoring

Prefers the sharpest, least-foreshortened frame that covers the plot — no oblique smearing.

Gap-fill

One pixel = one frame. Neighbours fill only the holes; oblique frames are a last resort.

Affine seam-match

Mean + contrast matched in the overlap — invisible joins, native pixels.

Ortho fallback

Edge plots auto-rebuilt from the ortho; white nodata → black.

Chunk aware

Reads a project's sub-projects; pick Day 1 vs Day 2 in one click.

GPU + parallel

GPU compute, multi-core image stage — 392 plots in minutes.

What you get

A dataset, plus its provenance

Per run

RawCrops\ — sharp upright plot images
OrthoCrops\ — deskewed nadir crops
manifest.csv — one row per plot

Every crop is accountable

The manifest records coverage, frames used, seam location, detected rows and the exact fitted area in m² — and flags any plot rebuilt from the ortho. Nothing is a black box.

Raw fidelity kept: natural per-plot brightness is preserved for downstream per-plot adaptive thresholding — the most raw image possible.
